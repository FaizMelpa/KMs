## ✦ Tech Stack

```
React 19 + TypeScript     →  Tampilan & logika app
Vite 6                    →  Build tool (cepat)
Tailwind CSS 4            →  Styling
Capacitor 6               →  Web → APK Android
localStorage              →  Database lokal di HP
GitHub Actions            →  Build APK otomatis di cloud
```

## ✦ Cara Restore Data

1. Buka app **KMs**
2. Tap ikon **⬇️** di pojok kanan atas
3. Tap **"Pilih File Backup"**
4. Pilih file `.json` dari folder Download
5. Data langsung masuk ✅
